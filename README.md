## What it does

`main.py` writes a single monologue of about 100 words to
`/output/entry.txt`. The speaker is a fantasy villain — a dark lord
with a crown behind the third door, an empty vault, a ledger to sign,
ravens that stopped answering, and a long history of heroes who came
to kill him and left. His tiredness never gets announced; it lives in
the pauses, the deflections, and the stairs that are not getting any
shorter.

## Run it

```sh
python3 main.py
```

Deterministic, no network, no input: every run writes the same
101-word text.
